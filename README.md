A modern, responsive portfolio website built with React.js, showcasing a diverse range of projects from web development to mobile apps and Kubernetes clusters.

## ⚙️ Installation & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Yashsingh045/my-portfolio1.git
   ```
2. **Navigate to the directory**:
   ```bash
   cd my-portfolio1
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Start the development server**:
   ```bash
   npm start
   ```
